# GrowthNest Digital - feature-rich SEO practice site

## Features
Dark/light mode, mobile menu, scroll progress bar, back-to-top, animated counters, service tabs, filterable work grid, monthly/yearly pricing toggle, testimonial slider, FAQ accordion, validated contact form, and a Free SEO Tools page (title/description length checker, keyword density, URL slug generator).
SEO built in: title, description, canonical, Open Graph, LocalBusiness and FAQPage schema, sitemap.xml, robots.txt, 404 page, alt text, image sizes, internal links.
