# GrowthNest Digital - feature-rich SEO practice site

## Features
Dark/light mode, mobile menu, scroll progress bar, back-to-top, animated counters, service tabs, filterable work grid, monthly/yearly pricing toggle, testimonial slider, FAQ accordion, validated contact form, and a Free SEO Tools page (title/description length checker, keyword density, URL slug generator).
SEO built in: title, description, canonical, Open Graph, LocalBusiness and FAQPage schema, sitemap.xml, robots.txt, 404 page, alt text, image sizes, internal links.

## Run locally
Extract the zip, open the folder in VS Code, right-click index.html > Open with Live Server (or double-click index.html).

## Deploy free (Netlify Drop)
1. Open app.netlify.com/drop and sign in.
2. Drag the extracted folder onto the page. You get a netlify.app address.
3. Replace `https://YOUR-SITE-URL` in all files (VS Code: Ctrl+Shift+H) with that address (no slash at the end). Replace you@example.com in index.html too.
4. Drag the folder again to update. Then submit sitemap.xml in Google Search Console.

Testimonials, prices and project numbers are sample data for practice.
